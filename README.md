# 평면도 가구 배치 도구

84A형 아파트 실측 평면도의 mm 치수를 기반으로 재구성한, 브라우저에서 바로 쓰는 가구 배치 시뮬레이터입니다.

## 사용법
- **온라인으로 열기**: GitHub Pages 링크로 바로 접속 (아래 참고)
- **로컬로 열기**: `index.html`을 더블클릭해서 브라우저로 엽니다. 별도 설치나 서버가 필요 없습니다.

## 기능
- **floorplan_84A.drawio 원본을 그대로 벡터로 렌더링** — 벽, 문, 붙박이 가구(아일랜드 장, 냉장고장, 신발장 등), 원본에 있는 모든 실측 치수선(회색 외벽/검정 내벽/청색 창호)을 도면 그대로 표시
- 사각형/원형 가구를 프리셋(침대, 옷장, 소파, 식탁, 냉장고 등)으로 추가하거나 직접 크기 입력, 원형은 모서리 드래그로 타원으로도 변형 가능
- 드래그로 이동(외벽 밖으로는 못 나가지만 방 사이 벽은 자유롭게 통과), 모서리 핸들로 크기 조절, 회전 버튼(±90°), Delete 키로 선택한 가구 삭제
- 가구 선택 시 **상하좌우 각 내벽까지의 거리를 mm 단위 파란 화살표**로 실시간 표시 (원본 도면의 검정/회색/청색 치수선과 구분되는 색상)
- **"📏 치수 추가"**로 도면 위 아무 지점이나 드래그해 직선거리를 재는 빨간 치수선을 자유롭게 추가/삭제 가능
- 캔버스와 참조 이미지 패널 모두 드래그로 화면 이동, 확대/축소 지원
- 상단 **"📐 평면도" / "📷 가상 도면"** 버튼으로 참조 이미지를 열어볼 수 있음 — 둘 다 확대/축소와 파일 저장(다운로드) 기능 포함
  - 📐 평면도 = 실제 시공도면 사진(floorplan_84A.jpg)
  - 📷 가상 도면 = **"평면도 가구배치" 캔버스와 똑같은 렌더링 함수·데이터로 그때그때 새로 그리는 벡터 뷰**. 별도로 저장해둔 이미지가 아니라 열 때마다 floorplan_84A.drawio에서 즉시 다시 그리므로, 캔버스와 절대 어긋나지 않습니다. "저장" 버튼은 그 자리에서 PNG로 내보냅니다.
- 브라우저 localStorage 자동 저장, 배치도 PNG 내보내기

## 파일 구성
- `index.html` — 도구 본체 (GitHub Pages로 배포됨). floorplan_84A.drawio와 실제 시공도면 사진을 base64로 내장한 완전한 단일 파일이라 로컬에서 더블클릭만으로도 그대로 열립니다.
- `floorplan_84A.drawio` — 벡터 평면도 소스 (draw.io/diagrams.net 형식). 방 구조나 치수를 직접 수정한 뒤 도구 코드의 `DRAWIO_B64` 상수만 교체하면 반영됩니다. "평면도 가구배치" 캔버스와 "📷 가상 도면" 패널 둘 다 이 파일 하나에서 매번 새로 그려지므로 항상 서로 일치합니다.
- `floorplan_84A.jpg` — 실제 시공도면 사진 원본 ("📐 평면도" 버튼에서 열림)
